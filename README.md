# 📦 Inventory Management System

## 1. Project Overview

The **Inventory Management System** is a simple project developed to manage products, inventory, shopping carts, and customer orders.

The project is initially developed using Python. A web-based frontend is also created using HTML, CSS, and JavaScript to provide a user-friendly interface.

This system helps users manage product information, calculate inventory value, add products to a shopping cart, and place orders.

---

## 2. Project Objectives

- To manage product details efficiently.
- To maintain product stock information.
- To calculate the total inventory value.
- To provide shopping cart functionality.
- To manage customer orders.
- To collect customer feedback.
- To understand basic programming concepts.

## 4. Project Features

### 1. Display Products
Displays all available products with their ID, name, price, and stock.

### 2. Add New Product
Allows users to add new products to the inventory.

### 3. Calculate Inventory Value
Calculates the total value of available inventory.

**Formula:**

Total Inventory Value = Price × Stock

### 4. Remove Product
Allows users to remove products from the inventory using their product ID.

### 5. Add Products to Cart
Allows customers to select products and specify quantities.

### 6. View Shopping Cart
Displays selected products, quantities, prices, and total cart value.

### 7. Place Order
Allows customers to confirm their orders and automatically updates product stock.

### 8. Customer Feedback
Allows customers to submit feedback about the system.

## 8. How to Run the Project

### Frontend

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure all three frontend files are in the same folder.
4. Install the Live Server extension.
5. Right-click `index.html`.
6. Select **Open with Live Server**.

### Python Version

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```
